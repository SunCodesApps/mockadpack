# MockAdPack

Generate professional ad mockups in multiple commercial formats with one click.

MockAdPack helps designers, developers and marketing teams quickly preview and export advertising creatives for different platforms and placements.

## Features

- Multiple ad formats support
- Real-time preview
- Export individual ads as PNG
- Export complete company packs as ZIP
- Export all companies as a single ZIP
- Platform format organization
- Customizable ad content
- Ready-to-use mockup templates

## Supported Formats

Examples:

- 300x250 — Medium Rectangle
- 728x90 — Leaderboard
- 320x50 — Mobile Banner
- 120x240 — Vertical Banner
- and more

## Platforms

Supported placements include:

- Google Ads
- Facebook
- Instagram
- YouTube
- Programmatic advertising

## Tech Stack

- React
- Vite
- Tailwind CSS
- html-to-image
- JSZip
- Font Awesome

## Export

MockAdPack generates:
```bash
MockAdPack.zip

├── Company A
│ ├── 300x250.png
│ ├── 728x90.png
│
├── Company B
│ ├── 320x50.png
│ └── 300x250.png
```


## Development

Clone the repository:

```bash
git clone https://github.com/yourusername/mockadpack.git
```

Install dependencies:
```bash
npm install
```
Run locally:
```bash
npm run dev
```
